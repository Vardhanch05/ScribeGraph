Here are the commands to run both the ScribeGraph Backend API and Frontend UI:

1. 🚀 Run Backend API (FastAPI)
Open a terminal in the project root (ScribeGraph) and run:

powershell
uv run uvicorn quantinsight.api.main:app --reload --port 8000
API Base URL: http://localhost:8000
Interactive Swagger Docs: http://localhost:8000/docs

2. 🎨 Run ScribeGraph Research UI (Next.js 16)
Open a second terminal in the `frontend` directory and run:

powershell
cd frontend
npm run dev
Frontend Application URL: http://localhost:3000

3. 📊 (Optional) Run Streamlit Dashboard
Open a terminal in the project root and run:

powershell
uv run streamlit run app/Home.py
Streamlit Application URL: http://localhost:8501

4. 🔌 (Optional) Run MCP Server (FastMCP)
If using ScribeGraph as an MCP Server with Claude Desktop, Cursor, or Windsurf:

powershell
uv run python -m quantinsight.mcp_server.server
